# Personal Value Lab（个人经济价值实验室）

一个面向中国用户的微信小程序：先用匿名、本地计算的“未来收入地图”帮助用户理解自己的**未来收入能力与职业路径**；在用户主动登录后，再逐步扩展到经济安全垫与完整财务规划。

> 它不是给人定价，更不是招聘、征信、相亲或信贷工具。它只是一套由用户掌控、可解释、可修改的个人财务教育模型。

## 为什么做

企业 DCF 估值关心的是未来可分配现金流的现值。迁移到个人时，最有价值的不是产出一个看似精确的“身价”，而是把问题说清楚：

- 收入的稳定性、增长性和中断风险分别是什么？
- 为保持收入能力，需要投入多少学习、健康与职业转换成本？
- 资产、负债和家庭刚性支出怎样共同影响安全垫？
- 如果行业、城市、健康或家庭责任发生变化，结果会怎样？

## 推荐产品命名

对外优先使用“个人经济价值实验室”或“人生现金流地图”，避免“人的市值”带来的物化、误读和合规风险。结果页建议称为：

- 个人经济净值估算（PEV）
- 人力资本现值（HCV）
- 财务安全垫（月数）

## 当前可运行版本：未来收入地图（原型）

当前原型已实现为原生微信小程序：

- 3 分钟匿名问答：年龄段、收入区间、工作状态、未来判断与可选目标；
- 本地、可测试的十年税后职业收入情景计算：默认按今天购买力维持，不默认长期增长；
- 中性收入路径标签与行动建议；
- 不含金额、年龄或职业信息的分享卡；
- 本机草稿、结果与行动保存，以及一键删除。

### 本地预览

1. 在微信开发者工具中导入本仓库根目录；
2. 使用测试 AppID 或在 `project.config.json` 中填写自己的小程序 AppID；
3. 编译并在模拟器/真机中预览。

计算内核不依赖小程序运行时，可单独验证：

```bash
npm test
npm run check
```

> 注意：原型仍采用“未来收入地图”的旧计算逻辑。下一轮开发会按《个人现金流 DCF 实验室重构方案》替换为“退休后现金流占比 / 严格终值占比”主线。

## MVP 的一句话

用少量职业信息，得到按今天购买力折算的未来十年职业收入地图与一条可行动建议；默认不上传、不公开、不进行人群比较。
